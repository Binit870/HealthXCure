# 🩺 Project Title - HealthXCure

HealthXCure is a comprehensive health-oriented web platform designed to assist users in finding doctors, participating in community discussions, accessing health tools, and navigating medical information with simplicity and accuracy.  
The system integrates modern web technologies and offers a seamless, intuitive, and powerful user experience.

## 🚀 Project Summary

HealthXCure aims to simplify access to healthcare-related information by enabling users to:

- Search for doctors based on state, city, specialization, or location
- Explore nearby doctors using geolocation
- Participate in a community forum with real-time updates
- Access health & nutrition resources
- Use an interactive map to get directions and routes to medical specialists

This project was developed as part of an academic initiative showcasing teamwork, modern development practices, and applied problem-solving.

## 📦 Core Features & Modules

### **1. Authentication Module**
- Register & Login  
- Secure JWT-based sessions  
- Full profile control  

### **2. Doctor Search Module**
- Filter by **State**, **City**, **Specialization**  
- Dynamic city filtering based on chosen state  
- Keyword search  


### **3. Community Forum Module**
- Create posts under multiple categories  
- Real-time updates using Socket.io  
- Delete own posts  
- Clean UI with Toast notifications  

### **4. Health Tools & Information**
- Nutrition insights  
- Fitness guidance  
- User-friendly, visually appealing dashboard
